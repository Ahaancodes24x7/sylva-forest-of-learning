 SYLVA, Forest of Learning

SYLVA is an interactive learning platform that helps students visualize their syllabus and learning progress in a different way. Instead of showing everything as a normal list of subjects and completed percentages, the project represents the learning journey through a virtual forest.

The main idea behind SYLVA is simple. As a student learns and completes different concepts, their forest grows. Different parts of the forest represent different areas of learning and progress. This makes it easier to understand how much of a course has been completed and which topics may need more attention.

## What the Project Does

SYLVA allows users to explore their learning progress through an interactive interface.

Some of the main features include:

- Interactive forest based learning visualization
- Course and concept tracking
- Learning progress dashboard
- Topic and concept details
- Revision and knowledge decay visualization
- Study timeline and workload view
- Syllabus upload flow
- Responsive interface for different screen sizes

The project currently focuses mainly on the frontend and user experience. Sample and mock data is used in some places to demonstrate how the application can work with actual student data in the future.

## Tech Stack

The project is built using:

- React
- TypeScript
- Vite
- Tailwind CSS
- Three.js
- React Three Fiber
- Framer Motion
- Recharts

These technologies are used to build the interface, handle the interactive visualizations, create animations, and display learning related data.

## Project Structure

The project is organized into different folders based on their purpose.

- `components` contains reusable UI components
- `data` contains data used for demonstrating the application
- `hooks` contains custom React hooks
- `lib` contains helper functions and utilities
- `routes` contains the main application routes
